BUMBLE NUMS AIRPLANE -- GAME-READY 3D MESHES

Files:
BumbleNums_Airplane_All.glb : combined airplane plus three characters
Airplane_Only.glb         : airplane with named propeller pivot
BumbleNum_Purple.glb     : standalone purple character
BumbleNum_Orange.glb     : standalone orange character
BumbleNum_Teal.glb       : standalone cyan character
BumbleNums_Airplane_All.obj : alternate OBJ geometry and vertex colors
model_preview.png         : illustrative software-rendered preview of actual geometry

Model notes:
* Genuine 3D triangle meshes; not a flat image or 2D plane.
* Stylized, unofficial fan-made approximation based on the visual reference provided in the conversation; not an official character asset.
* Y-up, aircraft forward is +Z; character roots at origin in standalone files.
* Import GLB into Godot by dragging to FileSystem and instantiate the scene.
* In Unity, install a glTF/GLB importer such as glTFast and import the GLB; alternatively import OBJ directly.
* In Unreal Engine, use the engine glTF import support / Interchange GLTF importer.
* Node names beginning BumbleNum_ allow selecting individual characters.
* Animate the Propeller_Spin_Pivot by rotating it around its local Z axis.
* Editable geometry: individual mesh objects per character part, airplane part.
* Static models (no skeletal rig, no included animation).
* Designed for prototyping; optimize/rig/UV unwrap as needed for final production.

Coordinate convention: meters-like stylized units; proportions approximate.
